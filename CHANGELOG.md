# Changelog

## 1.3.0 — 2026-10-15

- Native notch interface and active-terminal drawer powered by NotchworkKit 0.1.0.
- Porty app icon and lightweight status expressions, blinking, and error reactions.
- Project restart, pasted JSON handoffs, managed console input, and categorized output.
- Momentum-preserving surface transitions, Reduce Motion support, and bounded output delivery.
- Optional Notchwork sharing with Portkeeper’s own panel and validated start/stop/restart actions.
- Branded documentation and explicit empty defaults; no personal projects, ports, settings, or logs are bundled.
- Release privacy checks reject local settings files and absolute home paths.

Requires macOS 14+ and Apple silicon. Development binaries are ad-hoc signed and not notarized. Quitting an existing Portkeeper stops its managed services. The Notchwork dependency is licensed under PolyForm Noncommercial 1.0.0; commercial-use rights are not granted by that dependency.
