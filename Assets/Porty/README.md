# Porty

Portkeeper's small phosphor-green blob companion: satin-like shading, a distinctive raised bump, black pill eyes, and a simple smile. Original artwork generated for Portkeeper.

## Assets

- porty-icon-v2.png: production icon with larger eyes, square black background, 1254 × 1254 pixels.
- porty-icon.png: square black-background app icon, 1254 × 1254 pixels.
- porty-mascot.png: matching transparent PNG mascot, 1254 × 1254 pixels.

The icon was inspected at full size and at 48 pixels. Portkeeper uses the larger-eye icon. The notch uses a lightweight native-layer rendition of Porty, with expressions and occasional blinks; the original transparent mascot remains available for illustration use.
